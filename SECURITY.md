## Reporting a Vulnerability

We take the security of Coach Watts seriously. If you believe you have found a security vulnerability, please report it responsibly rather than opening a public issue.

### How to Report

- **Private Vulnerability Reporting**: Use the [GitHub Security Advisory](https://github.com/watt-mind/coach/security/advisories/new) reporting tab on the repository if available.
- **Email**: Send details of the vulnerability to [hdkiller@coachwatts.com](mailto:hdkiller@coachwatts.com).

### Information to Include

Please include as much of the following information as possible:

- Type of issue (e.g. SQL injection, XSS, unauthorized data access, privilege escalation).
- Full paths or endpoint URLs involved.
- Step-by-step instructions or proof-of-concept payload to reproduce the issue.
- Impact of the issue and potential mitigation steps if known.

### Response SLA

- **Initial Response**: Within 48 hours acknowledging receipt of your report.
- **Triage & Status Updates**: We will provide updates at least once a week until the vulnerability is addressed or determined to be non-actionable.
- **Public Disclosure**: We ask that you give reasonable time to fix the issue before making any public disclosure.
